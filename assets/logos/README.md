# 로고 이미지

렌더링된 쇼츠 상단 좌/우 코너에 들어갈 방송사 로고 이미지 파일을 여기에 넣는다.
아래 정확한 파일명으로 저장하면 `src/radihola/render.py`가 자동으로 인식해서
텍스트 자리표시자 대신 이 이미지를 사용한다. 파일이 없으면 그냥 텍스트로 대체되므로,
파일을 아직 안 넣어도 렌더링 자체는 정상 동작한다.

- `kbs1radio_wordmark.png` — 상단 **왼쪽** 코너 (KBS 1 Radio 워드마크, 전파 아이콘 버전)
- `kbs1radio_badge.png` — 상단 **오른쪽** 코너 (KBS 1라디오 알약형 배지 버전)

## 권장 사항

- 배경이 투명한 PNG를 권장한다 (배경이 불투명하면 영상 위에 로고 주변으로 네모난
  박스가 같이 보인다).
- 높이는 자동으로 70px로 맞춰서 표시되고, 가로는 원본 비율대로 늘어난다.
