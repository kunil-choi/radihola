GitHub 토큰 설정

"쇼츠 만들기" / "후보 뽑기"를 실행하려면 이 저장소에 대해 Actions 읽기/쓰기 권한이 있는 GitHub 개인용 토큰(fine-grained PAT)이 필요합니다. 토큰은 이 브라우저에만 저장되고 (localStorage), 다른 어디로도 전송되지 않습니다 — GitHub API를 브라우저가 직접 호출하는 데만 쓰입니다.

  1. GitHub 접속 → 우측 상단 프로필 → Settings
  2. 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access: "Only select repositories" → kunil-choi/radihola 선택
  4. Permissions: Actions = Read and write, Contents = Read-only
  5. 생성된 토큰 문자열을 복사해서 아래에 붙여넣고 저장
